# 🎓 Ravindra Engineering College for Women (RCEW) Website

A modern, responsive, and professional frontend website developed for **Ravindra Engineering College for Women (RCEW), Kurnool**.

The website is designed to provide students, parents, faculty, and visitors with an engaging experience while showcasing the college's academic excellence, departments, placements, faculty, campus life, and admissions.

---

## 🌐 Project Overview

This project is a complete frontend redesign of the official college website with a focus on:

- Modern UI/UX
- Responsive Design
- Professional Academic Appearance
- Fast Performance
- Clean Component-Based Architecture

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Mustabshira0987/ravindra.git
```

Move into the project

```bash
cd ravindra
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

The application will start on:

```
http://localhost:5173
```
